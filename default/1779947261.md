# 网页设计中常见的页面类型及其定位

## 核心规范

### 一、用户提供的 5 种类型

| 英文名称 | 中文常用称呼 | 核心定位 | 核心特点 |
|---|---|---|---|
| Homepage / Index | 首页、主页、索引页、门户页 | 网站主入口 | 多栏目、全导航、用途综合 |
| Landing Page | 落地页、着陆页、转化页、专题页 | 外链跳转页 | 单目标、弱导航、主打转化 |
| Splash Screen | 启动页、闪屏页 | APP 启动过渡 | 网页基本不用，纯展示 |
| Detail Page | 详情页 | 内容内页 | 承接流量，展示具体信息 |
| Sub Page | 二级页、内页 | 网站分支页面 | 隶属于首页，非独立引流页 |

### 二、补充的 6 种常见类型

| 英文名称 | 中文常用称呼 | 核心定位 | 核心特点 |
|---|---|---|---|
| About Us / Company | 关于我们、公司介绍 | 品牌信任背书 | 讲故事、秀实力、建信任，常含发展历程/团队/资质 |
| List / Category / Archive | 列表页、分类页、归档页 | 内容聚合分流 | 多条目陈列，带筛选/排序/分页，导航到详情页 |
| Contact | 联系我们 | 转化收口 | 表单+地图+联系方式，降低联系门槛 |
| Product / Service | 产品页、服务页 | 单品/单项详细展示 | 规格参数/案例/价格/CTA，核心转化场景 |
| Search Results | 搜索结果页 | 站内检索结果 | 关键词高亮、无结果引导、相关推荐 |
| 404 / Error | 404页面、错误页 | 异常兜底 | 友好的错误提示+回首页/搜索引导 |

## 注意事项

- **Splash Screen 非网页概念**：在网页设计中极少使用（更属于 APP 领域），网页对应的是 Loading / Preloader 或骨架屏
- **Landing Page ≠ Homepage**：落地页有明确单一转化目标（填表/下载/购买），导航极简；首页是多目标综合入口
- **Sub Page 范围过宽**：实际工作中「二级页」通常指导航菜单下的第二层级页面，建议具体化命名（如列表页、详情页、关于页等）
- **Detail Page 和 Product Page 的区别**：Detail 是泛内容详情（新闻/文章/案例），Product 专门用于商品/服务展示，后者更强调转化

## 适用场景

- 网站信息架构设计时，作为页面类型的标准术语参考
- 与客户沟通时用中文常用称呼，开发文档中用英文名称
- 竞品分析时按页面类型归类对比
