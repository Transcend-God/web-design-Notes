# 客户提供资料后响应规范

## 核心原则

**客户提供资料后，需要及时给到客户设计交稿时间**。

## 规范说明

| 环节 | 规范要求 |
|------|---------|
| 响应时效 | 收到客户资料后应尽快回复，不要让客户等待 |
| 内容 | 回复时需明确告知预计设计交稿时间 |
| 方式 | 主动发邮件或消息告知客户 |
| 目的 | 让客户心里有数，减少反复催促的沟通成本 |

## 注意事项

- 即使项目繁忙，也应给出一个预估时间，而不是不回复
- 如遇特殊情况无法按时交付，需提前告知客户并说明原因
- 交稿时间应结合当前项目排期合理评估，避免过度承诺

## 适用场景

适用于任何需要向客户交付设计成果的项目节点。
