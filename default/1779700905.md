# 浏览器兼容性范围规范

## 核心原则

每个项目启动时需明确浏览器兼容范围，作为设计和技术选型的依据。

## 标准兼容范围

| 浏览器 | 最低版本 | 优先级 | 说明 |
|--------|---------|--------|------|
| Chrome | 最近 2 个大版本 | ⭐ 最高 | 市场份额最大 |
| Edge | 最近 2 个大版本 | ⭐ 高 | Windows 默认浏览器 |
| Safari | 最近 2 个大版本 | ⭐ 高 | Mac/iOS 用户必经 |
| Firefox | 最近 2 个大版本 | 中 | 开发者群体使用多 |
| 移动端 Safari (iOS) | iOS 14+ | ⭐ 高 | iPhone 用户 |
| 移动端 Chrome (Android) | 最近 2 个大版本 | ⭐ 高 | Android 用户 |

## 是否兼容 IE？

| 情况 | 处理方式 |
|------|---------|
| 客户没有明确要求 | **不兼容 IE**（IE 已于 2022 年停止支持） |
| 客户明确要求 | 在项目启动会记录，评估额外工作量并单独报价 |

## 兼容性的技术影响

| 技术 | 兼容情况 | 替代方案 |
|------|---------|---------|
| CSS Grid | 主流浏览器均支持 | 无需替代 |
| Flexbox | 主流浏览器均支持 | 无需替代 |
| CSS 变量 | 主流浏览器均支持 | 无需替代 |
| WebP 图片 | Chrome/Edge/Firefox 支持，Safari 16+ | 提供 JPG 兜底 |
| AVIF 图片 | Chrome/Edge/Firefox 支持，Safari 16+ | 使用 WebP 或 JPG 兜底 |
| SVG | 全部支持 | 无需替代 |

## 与设计的关系

| 设计决策 | 兼容性考量 |
|----------|-----------|
| 圆角边框 | border-radius 全兼容，放心用 |
| 阴影效果 | box-shadow 全兼容 |
| 渐变背景 | linear-gradient 全兼容 |
| 高斯模糊 | backdrop-filter Safari 需 -webkit- 前缀 |
| 滚动动画 | 建议降级处理，低端机直接显示静态内容 |
| 自定义字体 | 提供 WOFF2 + WOFF 双格式 |

## 注意事项

- 兼容范围在**项目启动会邮件**中确认并记录（与启动会规范联动）
- 如需兼容非常规浏览器（UC、QQ浏览器等国产浏览器），需单独评估
- 移动端优先保证 iOS Safari 和 Android Chrome 体验一致

## 适用场景

适用于所有网站设计项目启动阶段的技术边界确认。
