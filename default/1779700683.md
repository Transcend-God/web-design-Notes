# 汇总页嵌套列表的三种处理方式

## 核心原则

汇总页中嵌套列表时，根据数据量与位置选择不同方案，优先级从高到低：

## 三种方式

| 方式 | 适用条件 | 具体做法 |
|------|---------|---------|
| 直接分页 | 列表在第一屏 | 加分页符号（1, 2, 3...），保持页面简洁 |
| 直接展示（不分页） | 数据量可控，量少 | 直接列出所有数据，不做列表/分页处理 |
| 加载更多 | 数据量不可控，且不在第一屏 | 用「加载更多」按钮代替分页符号，提升浏览体验 |

## 决策流程图

```
汇总页中嵌套列表
    │
    ├─ 数据量可控、量少？
    │   └─ 是 → 直接展示，不做分页
    │
    ├─ 在第一屏？
    │   └─ 是 → 加分页符号
    │
    └─ 数据量不可控，不在第一屏？
        └─ 是 → 加载更多（代替分页符号）
```

## 注意事项

- 第一屏用分页（用户期望明确），非第一屏用加载更多（避免打断浏览流）
- 数据量少时无需过度设计，直接展示即可
- 此处规则与列表页规范一致：非必要不做轮播

## 适用场景

适用于首页、频道页、专题页等汇总页面中嵌入内容列表的设计场景。
