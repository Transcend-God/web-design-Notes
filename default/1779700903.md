# 响应式设计断点规范

## 核心原则

配合 840px 一屏高度规范，建立标准响应式断点体系，确保设计稿在主流设备上适配一致。

## 标准断点

| 档位 | 宽度范围 | 对应设备 | 说明 |
|------|---------|---------|------|
| 超小屏 | < 576px | 手机竖屏 | 单列布局，导航折叠为汉堡菜单 |
| 小屏 | 576px ~ 768px | 手机横屏 / 小平板 | 可双列，但仍保持触控友好 |
| 中屏 | 768px ~ 992px | 平板竖屏 | 开始展示 PC 版部分布局 |
| 大屏 | 992px ~ 1200px | 平板横屏 / 小笔记本 | PC 版完整布局 |
| 超大屏 | ≥ 1200px | 台式机 / 大屏笔记本 | 标准 PC 设计稿以此为准 |

## 与 840px 一屏高度的关系

- **设计稿基准**：以 1200px 宽度出稿，一屏内容控制在 840px 高度内
- **向下适配**：从 1200px → 768px → 576px 逐级简化，不做等比缩放
- **移动端**：不做一屏高度限制，允许纵向滚动

## 适配策略

| 变化类型 | 做法 |
|----------|------|
| 栅格 | 多列 → 少列 → 单列 |
| 导航 | 横向菜单 → 折叠汉堡菜单 |
| 图片 | 等比缩放，移动端适当裁剪（如 Banner 人物居中裁切） |
| 表格 | 横向滚动 或 转为卡片列表 |
| 隐藏 | 非核心装饰元素在移动端可隐藏 |

## 注意事项

- 每个项目启动会时，根据客户目标用户群体调整断点范围
- 如需兼容低版本 IE，提前在启动会确认并记录
- 设计稿至少输出 PC（1200px）和移动端（375px）两版

## 适用场景

适用于所有网站设计项目的响应式适配环节。
