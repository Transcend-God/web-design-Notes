# 设备交互对比色安全规范

## 问题案例

某饮水机设计因**冷热水标识对比色差值太小**，导致老人误将热水壶接成了热水，存在严重安全隐患。

## 核心原则

涉及安全、冷热、开关等具有**危险含义的状态切换**，必须保证足够的视觉对比度。

## 规范建议

| 场景 | 规范要求 |
|------|---------|
| 冷/热水标识 | 红色=热水，蓝色=冷水，色差值 Δ≥30 |
| 开关状态 | 开启/关闭颜色对比明显，不可用相近色 |
| 危险操作按钮 | 使用警示色（红/橙），与常规按钮拉开差距 |
| 老年人产品 | 对比度至少符合 WCAG AA 标准（4.5:1） |

## 适用场景

所有涉及物理设备交互的界面设计，尤其是公共设备、医疗设备和老年人使用的产品。
