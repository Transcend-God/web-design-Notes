# 移动端视频格式规范

## 核心规范

- **格式**：移动端视频使用 **TS 格式**
- **编码**：编码使用 **MPEG-1**

## 说明

| 参数 | 规范值 |
|------|-------|
| 视频格式 | TS（Transport Stream） |
| 视频编码 | MPEG-1 |
| 适用场景 | 移动端视频播放 |

## 注意事项

- TS 格式（Transport Stream）适合移动端流媒体播放，兼容性好
- MPEG-1 编码在移动端设备上兼容性更广，避免出现无法播放的问题
- 如需适配不同移动端机型，优先考虑此组合

## 适用场景

适用于企业网站或项目中涉及移动端视频嵌入与播放的设计与开发环节。
