# VCF 电子名片文件的使用方法

## 核心说明

VCF（vCard）是标准的**电子名片文件格式**，常用于网站下载的联系人信息，下载后可直接导入通讯录，无需专业软件。

## 各平台使用方法

| 平台 | 操作 |
|------|------|
| Windows | 双击文件，用 Outlook 或 Windows 联系人打开，点击保存 |
| Mac | 双击或用"通讯录"App 打开，自动识别并保存 |
| iPhone | 用"文件"App 打开，自动弹出"创建新联系人" |
| Android | 通讯录 App → 导入 → 选择 .vcf 文件 |
| 微信 | 发送到微信中，点开可直接识别并添加联系人 |

## 注意事项

- VCF 是开源标准格式，跨平台通用
- 文件很小，通常只有几 KB
- 不可与 VFC（FontLab 字体源文件）混淆，两者完全不同

## 适用场景

适用于网站设计中，客户提供电子名片、或在网站上设置 VCF 下载链接供访客保存联系方式的场景。
