# 知识库：网站设计一屏高度规范

## 知识点描述

网站设计中，一屏高度尽量保持在 1K 屏中一屏 **840px** 高度设计。

## 客观性分析

✅ **合理** - 840px 是针对 1080p 屏幕（1K 屏）去掉浏览器工具栏、任务栏等占用后的可视区域高度，是业界通用的设计基准值

## 原理说明

### 🖥️ 为什么是 840px？

| 组成部分 | 高度 |
|----------|------|
| 1080p 屏幕总高度 | 1080px |
| 减去：浏览器标签栏 + 地址栏 | 约 -90px |
| 减去：Windows 任务栏 | 约 -48px |
| 减去：网站顶部导航栏 | 约 -60~80px |
| **实际可视内容区域** | **≈ 840px** |

### 📐 常见屏幕分辨率对照

| 屏幕分辨率 | 常见称呼 | 建议一屏高度 |
|------------|----------|-------------|
| 1920 x 1080 | 1K / FHD | **840px** |
| 2560 x 1440 | 2K / QHD | 约 1050px |
| 3840 x 2160 | 4K / UHD | 约 1800px |
| 1366 x 768 | 笔记本常见 | 约 600px |

## 设计规范

### ✅ 正确做法

- 每个主要 section（板块）的内容高度控制在 840px 以内
- 首屏（Hero Section）重要内容必须在 840px 内完整呈现
- 超出部分可滚动，但关键 CTA 按钮需在 840px 内可见

### ❌ 常见错误

- 设计稿画布高度随意拉长，不考虑实际可视区域
- 重要内容（如标题、按钮、核心信息）超出 840px 折叠区
- 只在 4K 或大屏下测试，忽略 1080p 用户体验

## 多设备适配参考

| 设备类型 | 参考一屏高度 | 备注 |
|----------|-------------|------|
| 桌面端（1080p）| **840px** | 主要设计基准 |
| 桌面端（1440p）| 约 1050px | 兼容处理 |
| 平板（iPad）| 约 900px（横屏）| 视具体设备 |
| 手机（375px宽）| 约 650px | 移动端单独设计 |

## 关键控制点

- ⚠️ **设计稿基准以 840px 为一屏单位**，避免内容被遮挡
- ⚠️ **首屏 Hero 区域最关键**，必须在 840px 内呈现完整视觉效果
- ⚠️ **浏览器/系统 UI 会占用空间**，设计时不能直接用 1080px 作为一屏高度
