# Figma画板导出PDF到Adobe Illustrator——白色区域问题与蒙层解法

## 核心问题

Figma 画板导出为 PDF 后，在 Adobe Illustrator（AI）中打开，**某些区域会显示为白色块**，遮盖了下层内容。

## 为什么会出白色块

| 原因 | 说明 |
|---|---|
| **混合模式不兼容** | Figma 的 Multiply/Screen/Overlay 等混合模式在 PDF 中不被原生支持，AI 解析时渲染为白色 |
| **模糊特效丢失** | Drop Shadow / Layer Blur / Background Blur 在导出 PDF 时被栅格化，边缘产生白色实底 |
| **透明度叠加** | 多层半透明对象叠加时，PDF 的透明度展平算法容易产生白块 |
| **渐变与遮罩** | Figma 的渐变叠加到 PDF 中，渐变透明部分被替换为白色填充 |
| **PDF 展平 (Flattening)** | Figma 导出 PDF 时会对复杂图层做展平处理，展平过程中透明区域可能被白色填充 |

## Frame 在 AI 中的问题（补充）

Figma 的 **Frame**（画板/容器）导出 PDF 后在 AI 打开，会出现以下问题：

| 问题 | 说明 |
|---|---|
| **Frame 变成 Clipping Mask** | Figma 的 Frame 本质是带裁剪功能的容器，导出后 AI 将其解析为剪切蒙版，导致图层结构混乱 |
| **Frame 背景色变白块** | Frame 的 Fill 色导成 PDF 后可能变为不透明的白色矩形覆盖下层 |
| **Frame 嵌套层级丢失** | Frame 内嵌 Frame 的层级关系在 AI 中会变为平铺 Clip Group，难以编辑 |
| **Frame 圆角丢失** | Frame 的 Corner Radius 导出为 PDF 后可能失效，变为直角 |
| **内容溢出被裁掉** | 如果 Frame 设置了 Clip Content，超出边界的内容在 AI 中可能永久丢失 |

### Frame 的替代方案

| 场景 | ❌ 不要这样做 | ✅ 改为 |
|---|---|---|
| 需要背景色 | 给 Frame 加 Fill | 在 Frame 内部最底层放一个全尺寸矩形 |
| 需要圆角容器 | 给 Frame 加圆角 | 用一个带圆角的 Rectangle 做 Mask |
| 需要裁剪内容 | 打开 Clip Content | 用 Rectangle 做 Mask 裁剪 |
| 需要分组 | 嵌套多层 Frame | 用 Group（Cmd+G），导出后图层结构更干净 |
| 局部内容区 | Frame 套 Frame | 用矩形描边 + 内部 Auto Layout Group |

### 最佳实践

> **在 Figma 里，Frame 当画板用（顶层），不当层组的容器用（内层）。内层分组用 Group 或 Auto Layout 的矩形替代。**

## 解决方案：在 Figma 中用蒙层替代

### 方案一：手动蒙层替代阴影

**不要**在 Figma 中给对象直接加 Drop Shadow 效果。

**改为**：
1. 复制需要阴影的形状
2. 填充黑色，降低图层不透明度（不用混合模式）
3. 加 Layer Blur 并放在原形状下方
4. 用一个遮罩框（Mask）裁剪阴影范围，确保边缘干净

### 方案二：蒙层替代半透明叠加

**不要**用半透明图层 + Multiply 混合模式做叠加。

**改为**：
1. 把要叠加的颜色做成纯色形状
2. 用 Mask 功能裁剪到目标区域
3. 在 AI 中打开后手动调透明度（AI 对纯色透明比混合模式友好得多）

### 方案三：渐变底部垫纯色

**不要**只用渐变透明来做过渡。

**改为**：
1. 渐变层先垫一个同色系的纯色底
2. 渐变透明度不要降到 0，最低保留 5-10%
3. 或者渐变两端都用实色（不用透明色）

### 方案四：出口前检查清单

| 检查项 | 说明 |
|---|---|
| ❌ 避免 Drop Shadow 特效 | 改用手动阴影层 |
| ❌ 避免混合模式（Multiply/Screen 等） | 改用纯色 + Mask 裁剪 |
| ❌ 避免 Background Blur | 导出 PDF 必然栅格化 |
| ❌ 避免 Inner Shadow | 改用内描边 + 实体形状模拟 |
| ❌ 内层不要用 Frame 嵌套 | 改用 Group / 纯矩形做容器，避免 AI 中 Clipping Mask 混乱 |
| ❌ Frame 不要加 Fill 做背景 | 改在 Frame 内最底层放矩形 |
| ✅ 能用 Mask 就用 Mask | 蒙层在 PDF→AI 中保留最好 |
| ✅ 导出前做一次本地测试 | 先导一页看效果，别全量导出 |
| ✅ 复杂渐变先栅格化 | 如果渐变必须用，在 Figma 里先 Flatten |

## 推荐的 Figma → AI 工作流

```
1. 检查并替换所有特效为蒙层方式
2. 使用 Figma 导出 PDF（导出设置选 PDF，质量 100%）
   → File → Export → PDF
3. 在 AI 中打开 PDF（File → Open，不是 Place）
4. 检查白块区域，回到 Figma 针对性修复
5. 最终确认后交付 AI 文件
```

### 导出设置建议

| Figma 导出选项 | 建议值 |
|---|---|
| Format | PDF |
| Quality | 100% |
| Include background | 勾选 |
| Scale | 1x（原始尺寸） |
| Export selected | 仅导需要的画板 |

## 注意事项

- **AI 打开 PDF 后是矢量文本**，字体可能需要安装对应字体，否则会回退
- **文字图层**：在 Figma 中 Outline 化（Shift + Cmd + O）的字体会保留形状，但失去可编辑性。原则：如果需要在 AI 中编辑文字 → 不转曲，但要提供字体文件；如果只是看效果 → 转曲
- **Mask 的边界要干净**：Figma 中 Mask 超出画板的部分不会影响导出
- **复杂页面分两次导**：如果一页内容很多，拆成背景层 + 前景层分别导出，在 AI 中对齐
