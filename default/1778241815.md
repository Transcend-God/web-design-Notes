# 设计工时报价流程规范

## 核心原则

设计师报给技术的工时**不要给客户看到**。

## 完整流程

1. **设计师 -> 技术**：设计师找技术评估工时，生成内部工时记录
2. **销售重新评估**：销售收到技术工时后，需**自行重新评估**后再发给客户（不得直接转发技术工时）
3. **客户确认**：客户确认工时无误后
4. **商务报价**：再将工时发给商务进行正式报价

## 注意事项

- 技术工时属于内部参考数据，直接发给客户可能导致报价偏高或偏低
- 销售需要综合考虑项目复杂度、市场行情等因素重新评估
- 确保客户确认的工时与最终商务报价一致

## 适用场景

适用于设计项目中涉及技术工时评估的所有报价流程。
